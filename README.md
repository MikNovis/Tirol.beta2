# Тироль · La Famille Group

Сайт банкетной площадки «Тироль» (Красноярск, ул. Регатная, 4). Кейтеринг — на сайте La Famille Group: https://lafamille.group/project/kejtering-lafamille-group/
Обычный статический сайт: HTML + CSS + JavaScript, без сборки и зависимостей.

## Структура

```
index.html        — страница площадки «Тироль»
css/style.css     — все стили сайта (общие для обеих страниц)
js/main.js        — скрипты: шапка (как на lafamille.group), панель «Проекты», галерея с просмотром фото, блок «Пять поводов»
images/           — фотографии в WebP, каждая в двух размерах: *-800.webp (телефоны) и большой (компьютеры)
fonts/            — шрифты WOFF2, те же, что на lafamille.group: CormorantSC, Jost, DeniStina, FuturaNew
robots.txt        — правила для поисковых роботов
sitemap.xml       — карта сайта для Яндекса и Google
```

## Единый стиль с lafamille.group

Шапка (логотип, меню «Программа лояльности · О нас · Карьера · Новости · Акции · Проекты», панель со всеми проектами группы), первый экран и шрифты повторяют страницы проектов на lafamille.group. Стили шапки и первого экрана собраны в конце css/style.css в разделе «Шапка и первый экран — как на lafamille.group».

FuturaNew и DeniStina — коммерческие шрифты из темы lafamille.group: используйте их только в рамках лицензии группы, репозиторий лучше держать приватным.

### Шкала шрифтов

Все размеры текста взяты из темы lafamille.group и заданы переменными в css/style.css (раздел «Шкала шрифтов»): `--fs-h2` заголовки разделов, `--fs-sub` крупные цифры и подзаголовки, `--fs-h3` заголовки карточек, `--fs-body` текст, `--fs-small` подписи, `--fs-script` рукописные надписи, `--fs-btn` кнопки. Размеры привязаны к ширине экрана и перестраиваются на 1024 и 525 px, как на сайте группы.

## ⚠️ Перед публикацией: адрес сайта

В файлах стоит заглушка `https://SITE-URL`. Замените её на настоящий адрес сайта (без `/` на конце),
например `https://tirol.lafamille.group` или `https://логин.github.io/репозиторий`:

- `index.html` — теги `canonical`, `og:url`, `og:image` и разметка Schema.org;
- `sitemap.xml`;
- `robots.txt`.

Проще всего — «Найти и заменить во всех файлах» в редакторе кода (VS Code: Ctrl+Shift+H).

## Что сделано для SEO и скорости

**Поиск**
- Один `h1` на странице, логичная структура `h2`/`h3`, `alt` у всех фотографий.
- `canonical`, Open Graph и Twitter Card — красивое превью при отправке ссылки в Telegram, VK, WhatsApp.
- Разметка Schema.org (JSON-LD): площадка (`EventVenue` + `LocalBusiness`, адрес, телефон, вместимость),
  организация La Famille Group, частые вопросы (`FAQPage`).
- `robots.txt` и `sitemap.xml`.

**Скорость**
- Фото в WebP, адаптивные `srcset`/`sizes`: телефон скачивает версию 800 px, компьютер — до 1600 px.
- У всех фото заданы `width`/`height` — страница не «прыгает» при загрузке.
- Ленивая загрузка (`loading="lazy"`) для всего ниже первого экрана; главное фото — с приоритетом и предзагрузкой.
- Шрифты в WOFF2 (в 2–3 раза легче TTF), `font-display: swap` — текст виден сразу, предзагрузка основных шрифтов.
- Скрипт подключён с `defer` и не блокирует отрисовку.

## После публикации

1. Добавить сайт в **Яндекс Вебмастер** и **Google Search Console**, подтвердить права, отправить `sitemap.xml`.
2. В Яндекс Бизнесе и 2ГИС указать ссылку на сайт в карточке «Тироля».
3. Проверить разметку: [валидатор Яндекса](https://webmaster.yandex.ru/tools/microtest/) и [Rich Results Test](https://search.google.com/test/rich-results).
4. Проверить скорость: [PageSpeed Insights](https://pagespeed.web.dev/).

## Фотографии

| Файл | Источник |
|---|---|
| `tirol-*` | архив площадки (снимки с мероприятий в «Тироле») |
| `terrace-*`, `wedding-cake-*` | фотограф Валерия Полховская, банкет 06.06.2026 — только кадры без людей |

Чтобы заменить фото: сделайте две версии в WebP (ширина 800 px и до 1600 px), положите в `images/`
и поменяйте пути в `src`, `srcset` (и `data-image` для галереи) в HTML.

## Публикация на GitHub Pages

1. Загрузите содержимое этой папки в корень репозитория.
2. **Settings → Pages → Build and deployment → Deploy from a branch**, ветка `main`, папка `/ (root)` → **Save**.
3. Через 1–2 минуты сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.
